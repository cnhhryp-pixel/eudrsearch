EUDR HS Code Guide

A practical explanation of why HS and CN codes matter when deciding whether a product is covered by EUDR.

Why the code matters

EUDR does not cover every product made from a relevant commodity. Scope is tied to the products listed in Annex I using EU Combined Nomenclature classifications.

What “ex” means

An “ex” prefix means only part of a customs heading is covered. You need the detailed product description and subheading, not just the broad heading number.

Recommended workflow

  1. Confirm the product’s customs classification.
  2. Search the current Annex I for that code.
  3. Read any “ex” wording or material limitation.
  4. Check whether a 2026 scope amendment affects the product and its start date.
  5. Document the classification source used for your compliance file.
