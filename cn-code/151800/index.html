ex 1518 00 — Chemically modified palm-derived oils

EUDR scope reference for selected chemically modified palm-derived oils and mixtures under ex 1518 00.

Commodity

Oil palm

Status

Added by the 2026 Annex I update

Application date

30 December 2027

Why this code matters

The entry applies only to the stated palm-derived portion of the heading and excludes qualifying waste.

Exact-scope warning

Where Annex I uses “ex”, only the stated part of the customs heading is covered. Product composition, production input and stated exemptions can change the result.

Official source — Delegated Regulation (EU) 2026/2102Current 2026 Annex I product-scope amendment.
